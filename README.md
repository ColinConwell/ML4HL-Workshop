## Notebook Setup

The first code cell downloads a small helper ZIP from this public repository and verifies its SHA-256 checksum before importing it. The filename identifies the exact Python, JavaScript, and CSS version used by that notebook. Internet access is required for setup; neither Git nor a repository clone is needed.

`python scripts/to_colab.py` regenerates the notebook and its deterministic archive under `assets/helpers/`. Publish both together. The publisher retains earlier helper archives so existing notebook copies continue to work. Changes to helper code create a new archive filename; do not replace or delete published historical archives.

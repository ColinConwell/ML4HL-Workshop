# Tutorial Assets

`visna-logo.jpg` is the unmodified VISNA Lab logo supplied for this tutorial by Colin Conwell. It was retrieved on October 28, 2026 from [the VISNA Lab website](https://visnalab.ccny.cuny.edu/wp-content/uploads/2024/08/visna_logo_Aug2024-1024x1024.jpg). Keep its original colors, proportions, and white background.

`visna-logo-rounded.svg` embeds that original JPEG unchanged and clips its outer corners for the Colab header. Colab removes inline `border-radius` styles, so the rounded outline is part of the SVG presentation instead.
